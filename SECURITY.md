# Security

To report a suspected security vulnerability in the Hermes integration, use
[GitHub private vulnerability reporting](https://github.com/Spawn-Backrooms/hermes-spawn/security/advisories/new).
Do not put exploit details, credentials, or customer information in a public issue.

Include the affected plugin version or commit, the affected host and version,
and clear reproduction steps using synthetic data where possible. Avoid including
secrets, wallet signatures, private job briefs, or unredacted logs in the report.

For ordinary bugs and feature requests, follow [CONTRIBUTING.md](CONTRIBUTING.md).
